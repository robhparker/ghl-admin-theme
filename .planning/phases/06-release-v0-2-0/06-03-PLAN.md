## Phase Goal

v0.2.0 ships to the agency with confidence: the release is versioned, every menu item and refusal path has been proven on a real Xcelsior owner and member, and staff can be put back on v0.1.2 by changing one tag.

Pushing main publishes every unpushed commit to a public repository. Three of those commits (86b53d7, 1d5dc04, 4cd4085) still carry live-looking Hint patient ids, and 86b53d7 quotes one in its message. None of them has ever been pushed. This plan rewrites only that unpushed range, replacing each id with the EXAMPLE id the Plan 06-02 scrub chose, in content and messages. It runs before the release commit (Plan 06-04) exists, so the release sha that Rob tests and approves is born after the rewrite and never changes. A local backup branch keeps the rewrite reversible (D-02).

<objective>
Write `harness/scrub-history.cjs` and prove it on a scratch branch (`--preview`: eight checks, main untouched). Then run `--apply`: create the local backup branch, then move main to the rewritten history with one compare-and-swap. Finish with `prepush-scan.cjs --history` exiting 0, an unchanged working tree, green suites, and nothing pushed or tagged.

Purpose: the checker's publication property and D-02. No release path publishes a patient id, and history cleanup is a planned step that happens before the release sha exists.
Output: one commit (the driver, rewritten along with the rest), a rewritten main, and the local branch backup/pre-scrub-<YYYYMMDD>.
</objective>
