## Planner assumptions carried from 02-01

A-01..A-10 apply unchanged. Additional for this plan:

- **A-11 Single observer.** "A single branding observer" (SC5) means one `MutationObserver` instance. It observes three targets: the region root returned by `adapter.findLogoRoot` (`childList`, `subtree` — sees the img replaced anywhere inside the sidebar), the root's parent (`childList`, shallow — sees the whole sidebar replaced, invisible from inside), and the img itself (`attributes`, `attributeFilter: ['src', 'alt']` — sees HighLevel resetting the logo on the same element). The instance is created when a non-native tier is applied or resolving and disconnected when native is showing, so agency-level pages with no agency logo carry no branding observer.
- **A-12 Self-inflicted rule for attributes.** An attribute record on the img is self-inflicted when the attribute's current value equals what the customizer last wrote (`appliedSrc` for `src`, `appliedAlt` for `alt`). Anything else is HighLevel's write: the native capture is updated to the new values and one coalesced rebrand is scheduled. childList records are always HighLevel's (the customizer adds no nodes to the sidebar) and schedule one coalesced rebrand; the rebrand is an idempotent reconcile, so a burst of unrelated sidebar mutations costs one no-op pass.
- **A-13 Live check config.** The live HighLevel confirmation uses a temporary config served the way Phase 1 served its test assets (HTTPS test host, injected with `data-config`/`data-css` into Rob's logged-in Chrome tab). That temporary config points `locations.iDPNGKoFsjvf9wUCrk3V` (Dummy Clinic) at a public HTTPS PNG with an alpha channel and points the `sendInvite` webhook at an inert HTTPS placeholder so the walkthrough can never fire the real workflow. The committed `config/agency-config.json` gains only `agency.logoMount`; Phase 3's DLV-02 adds the two demo location overrides.
